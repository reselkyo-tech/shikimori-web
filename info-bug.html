Softban, kompatibilitas device, dan tips kirim

WA Softban

  • Apa itu softban

    WhatsApp membatasi akun sender (limit / throttle). Bot masih terlihat online, tetapi pengiriman chat dan bug tidak sampai efektif ke target.

  • Ciri kena softban

    Status di Jester menunjukkan bug terkirim, tetapi target tidak ada efek sama sekali (no effect) setelah beberapa percobaan.

  • Solusi

    Ganti nomor sender, kurangi frekuensi attack, atau tunggu pemulihan limit WA sebelum lanjut loop.

Device & Target

  • Device tidak bisa dibug

    Sebagian tipe HP / versi WhatsApp / build OS lebih resisten. Hasil bug bisa berbeda per device — bukan semua target merespons payload yang sama.

  • Centang biru (read receipt)

    Target dengan centang dua (pesan dibaca) tetap bisa kena bug. Status read bukan jaminan kebal. Sebaliknya, no effect bukan berarti payload gagal total — cek softban sender dulu.

  • Cloud API / Business

    Nomor yang memakai WhatsApp Cloud API, C2, atau infrastruktur Business resmi sering tidak terpengaruh. Uji ke nomor personal biasa untuk baseline.

Tips kirim

  • Riwayat chat

    Target yang pernah chat dengan sender (idealnya ada balasan) cenderung lebih mudah dikenai payload. Chat dingin / tanpa interaksi hasilnya sering lemah.

  • Satu bug per sesi

    Uji satu jenis bug dulu. Minta target buka chat dari nomor sender — banyak payload baru aktif setelah chat dibuka.
